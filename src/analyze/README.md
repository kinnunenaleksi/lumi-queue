# Analyze

Functionality to combine and analyze the model training results.

## Structure 

| File    | Description |
| -------- | ------- |
| [`analyze.py`](analyze.py)    | Cleans and parses data.  |
| [`visualization.py`](visualization.py) | Helper functions for visualizations.     |
| [`utils.py`](utils.py) | Auxillary functions for both above.     |

## Usage 

The main function of this module is the `analyze.combine_results`, that combines the training
results from the [`train`](../train/README.md)
